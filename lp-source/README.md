# LP Construction source material

Drop the owner's material here. Git ignores everything in this folder except
this file and `owner-intake.md`, because originals can carry client home
locations (photo GPS), client names and prices.

- `media/`: original photos and videos straight from his phone, unedited and
  not renamed. Copies made for the site go under `public/` later.
- `invoices/`: past estimates or invoices, with customer names blacked out.
- `reviews.md`: full text of any real reviews, with where each one came from.

`owner-intake.md` holds the questions, his answers and the status of each.
Record new answers there.

What's confirmed so far, and from where, is in
`docs/demos/lp-construction.md`.
