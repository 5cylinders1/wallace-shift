# Owner business dashboard

Mode: Operate. This extends the existing client portal at `/client-portal?view=business`; it does not replace the client agreement and payment experience.

The owner needs to see business activity across systems, identify missing or delayed evidence, and give agents a reliable reporting context. Preserve the portal's Manrope typography, pearl surfaces, ink text, azure controls, and compact dividers. Use plain language and named sources rather than ornamental charts or invented sample results.

The overview prioritizes data coverage and operational observations. Website and SEO reports, channel connections, and agent context are accessible from the dashboard navigation. A fixed 7/30/90 day selector keeps comparisons scoped. Current operational balances and recent activity windows must state their own scope instead of pretending every metric shares the selected range.

The source is the unit of trust. Each report includes connection state, check time, processing/freshness limitations, available-through date when known, and metric definitions. No connection is inferred from a configured identifier alone. Missing permission, unsupported metrics, incomplete data, failed upstream calls, and true zero activity remain distinct.

Agent briefings in this version are deterministic observations of the snapshot. They must not imply an AI model was called, a recommendation was executed, or an autonomous agent is running. The snapshot is read only. Future sending, publishing, spending, and record changes need separate capabilities and audit records.

Responsive behavior: sidebar becomes a compact navigation region, controls wrap, and tables scroll within named containers. Preserve visible keyboard focus, clear status text, recoverable errors, loading feedback, and honest empty states. Do not expose secrets or private message bodies in the dashboard or exports.
