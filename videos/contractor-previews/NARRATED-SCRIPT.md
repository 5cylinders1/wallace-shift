# Narrated script entry point

The executable scene manifests below are the authoritative spoken scripts and screen directions for the current films. A scene's `spoken` value is the exact narration; `setup` identifies off-camera preparation, `actions` identifies visible interaction, `expect` identifies a resulting state, and `label`/`disclosure` preserve claim boundaries. Changes to spoken wording require updated narration and timing before composition.
